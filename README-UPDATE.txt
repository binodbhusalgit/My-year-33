MY YEAR 33 — VERSION 2.0

KEEP YOUR SAVED RECORDS
1. In the CURRENT app on your iPhone, open Journal and export a JSON backup (recommended before updating).
2. The app continues using the SAME localStorage key my-year-33-v1 and adds phdApplications and settings.reminders. Existing entries are not deleted.
3. Upload the 5 application files in this folder to your EXISTING public GitHub repository My-year-33 (the same root folder). Do not upload the outer folder or ZIP. You may leave README.md unchanged.
4. GitHub: Code > Add file > Upload files, select the 5 files, then Commit changes. GitHub Pages main /(root) should publish automatically.
5. Reload the website in Safari; installed home-screen app may need to be fully closed and reopened once or twice due to old offline cache. No reinstall needed.
6. Check existing habits and journal notes before entering new data. If needed, use the JSON restore feature with your earlier backup (note: restoring an older backup REPLACES all later entries).

REMINDERS: Version 2 provides due reminders while app is open; for reliable background alerts, create repeating events in Apple Reminders or Clock. No push server is included.
PRIVACY: public GitHub source files contain only code. Your daily diary and applications live in local browser storage; device/browser profiles do not synchronize. Export backups regularly.
